## مراجعة قبل الاستيراد
1. طابق كل اسم مع الأصناف الموجودة بالهوية المنطقية، مش بتطابق النص الحرفي؛ فيه أخطاء كتابة واختلاف تسميات.
2. تأكد من ترتيب الأسعار للنوع «عجل/ضاني» في عمود المشويات، وأحجام كول سلو وتومية، وأي إضافة سعرها غير واضح.
3. إضافة الموزاريلا للسندوتشات = **17 جنيه** حسب الصفحة الثانية، والإضافات لا تُكرر كمنتجات مستقلة.
4. صورة المنيو لا توضح الصور الأصلية لكل منتج أو الرصيد أو التوفر: تُترك دون افتراضات وتراجع قبل النشر.
5. راجع عنوان الفرع وبيانات التواصل؛ الصورة تشير إلى **مدينة السادات** بينما الموقع المنشور يعرض **الإسكندرية**.
